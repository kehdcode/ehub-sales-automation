# Proposal template (paste into a Google Doc)

Create a Google Doc, style it with Ehub branding, and use these placeholders exactly.
The automation copies this doc for every prospect and replaces each `{{placeholder}}`.
Put its ID (the long string in the doc URL) in `PROPOSAL_TEMPLATE_DOC_ID`.
